# THEOLOI roadmap

1. **Source foundation:** giữ module AudioTP, chuẩn hóa monorepo/audit/GitHub (đợt hiện tại, xem TASKS).
2. **Private media:** user-run B10, review quyền phục vụ, configure/deploy Worker và kiểm thử live. Không public bucket.
3. **Windows release:** Rust/MSVC/SDK, native build/WebView2/máy sạch, installer/signing/update; chưa có release được xác minh.
4. **Sheets:** review identity tách quyền, nguồn được phép, integrity và editions; không tự tải BookVN.
5. **Mobile/shared:** nghiên cứu khi Windows/backend ổn định; tách shared code khi có hai app sử dụng thật.
